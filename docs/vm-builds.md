# Сборка интерфейса для ВМ

1. Выполнить `npm --prefix frontend run build`. Vite очищает dist и записывает SHA-256 каждого файла в `frontend/dist-manifest.json` вне встраиваемой папки.
2. Выполнить `python deploy/sync-frontend.py` (по умолчанию tdcadmin@192.168.1.84, /home/tdcadmin/ngpanel-home-review). Другой хост и исходный checkout задаются через --host и --workspace.
3. В workspace ВМ выполнить `python3 deploy/sync-frontend.py --verify`, затем сборку Go. deploy/build-release.sh и исходная ветка deploy/install-panel.sh выполняют проверку автоматически.

Перенос упаковывает ровно перечисленные файлы, проверяет SHA-256 архива и содержимого, разворачивает в соседнюю временную папку и заменяет dist целиком. Неуспешная проверка сохраняет старый интерфейс; ошибка замены возвращает предыдущую папку. Временные файлы удаляются. Старые hashed JS/CSS не переносятся из прежних сборок.

Не используйте `scp -r frontend/dist .../frontend/`: Go embed включит и оставшиеся старые bundles, увеличивая бинарник и кеш каждой следующей сборки. Размер текущей папки интерфейса около 3 МБ.

Две последние ручные резервные копии приложения достаточны для локальных обновлений. Встроенный откат опубликованного релиза в /var/lib/ngpanel/updates/previous хранится отдельно. Кеш компилятора очищается командой `go clean -cache` от имени пользователя сборки; исходники, кеш загруженных модулей и рабочие базы удалять не требуется.
