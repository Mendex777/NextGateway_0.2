Как работают группы

Группа — отдельный выход: назначьте её правилу, устройству или маршруту по умолчанию. Создание группы не меняет маршруты. От 2 до 8 участников, до 16 групп.

Режимы порога и отказа требуют работающей панели. Общий наблюдатель использует наименьший интервал используемых групп.

Дополнительные настройки DNS
Как это работает

DNS: IPv4 означает обычный UDP/53; https://…/dns-query — защищённый DoH. Серверы проверяются по порядку при ошибках. В режиме по правилам учитываются включённые доменные правила и geosite сверху вниз; DNS использует тот же выход, включая конкретное подключение. IP-правила и правила отдельных устройств не участвуют: DNS-кеш Xray общий. Остальные домены используют маршрут по умолчанию. Резервные DNS для VPN тоже идут через VPN. DoT пока не поддерживается. A/AAAA идут по выбранной DNS-политике; остальные типы записей (например TXT/MX) пересылаются на Bootstrap DNS напрямую. Bootstrap DNS разрешает адреса VPN и DoH серверов напрямую.

Подключение устройств к шлюзу

После сохранения нажмите «Применить конфигурацию». Затем у тестового устройства задайте шлюз и DNS {{.Network.Address}}. При остановленном Xray включённый перехват блокирует TCP/UDP; панель остаётся доступной. ICMP и другие протоколы проходят обычную IPv4-маршрутизацию через провайдера.
